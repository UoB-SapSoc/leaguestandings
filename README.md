# SapSoc League Standing Website

A static, GitHub Pages–ready website for the pool league. It reads
`data/league.db` (a SQLite database matching the provided schema) directly
in the visitor's browser using [sql.js](https://sql.js.org)

## Where does the data come from?

Good question! The data is collected by an integrated application built by [@WilfMon](https://github.com/WilfMon).
There you will find the schema.sql file that builds the database.
[UoB-SAPSOC---Pool-League-Manager](https://github.com/owner/UoB-SAPSOC---Pool-League-Manager)
